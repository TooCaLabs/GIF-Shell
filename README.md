# GIF SHELL is a shell, fork of FISH, that includes upgrades, and the same autocomplete, still for free

This **shell** includes entire *settings*, and yes, still *free*

## How to install:

run:
```bash
git clone https://github.com/TooCaLabs/GIF-Shell.git
./install.sh
```

then set the *shell* to be the current one:
```bash
gif
```
